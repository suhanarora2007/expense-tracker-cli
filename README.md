# Expense Tracker CLI

A simple command-line interface application built in Python to track and manage personal expenses.

## How to Run

1. Open your terminal and navigate to the project directory.
2. Run the following commands to interact with the application:
# Add an expense
python expense_tracker.py add --desc "Lunch" --amt 20

# View all expenses
python expense_tracker.py list

# View total summary
python expense_tracker.py summary

# View summary for a specific month
python expense_tracker.py summary --month 8
```
